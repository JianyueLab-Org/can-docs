# CAN 管制员准则

**为规范管制员在 Cerulean Aviation Network（“CAN”）提供管制服务时的职业行为，明确管制员的资格、训练、权限与纪律，保障在线机组的飞行体验与安全，制定本准则。**

本准则是[《Cerulean Aviation Network 平台总则》](/zh_CN/regulation)在管制领域的细则，由 Cerulean Aviation Network 管理组发行及修订。

## 第一章　总则

**第一条（目的）**　为确保管制员在服务过程中保持专业、公正、高效的态度，维护 CAN 管制团队的声誉与利益，同时保障所有用户的安全和权益，制定本准则。

**第二条（适用范围）**　本准则适用于所有连接到 CAN 服务器的管制员。管制员连接到 CAN 服务器，即视为同意并认可遵守本准则。

**第三条（与《平台总则》的关系）**　管制员除遵守本准则外，还应当遵守[《平台总则》](/zh_CN/regulation)。两者不一致的，以《平台总则》为准。

**第四条（用语定义）**　本准则中下列用语的含义是：

（一）“席位”，指管制员在服务器上占用的管制位置，其代码与频率由分部公布；

<span class="regulation-status regulation-status-notice">（二）“权限”，指管制员经其主分部训练、考核后取得的，可以独立提供服务的最高席位等级；</span>

<span class="regulation-status regulation-status-notice">（三）“教员”，指经分部主管任命或者管理组指派、负责指导管制员训练的人员；</span>

<span class="regulation-status regulation-status-notice">（四）“实习期”，指管制员通过考核并获得权限后的一段时间，具体期限由该管制员主分部的主管或者责任教员确定，并告知本人；</span>

<span class="regulation-status regulation-status-notice">（五）“分部”，指平台按照地区设立、负责对应地区管制员事务及管制运行管理的组织；</span>

<span class="regulation-status regulation-status-notice">（六）“主分部”（Home Division），指管制员主要所属的分部，负责该管制员的训练、考核与权限管理；</span>

<span class="regulation-status regulation-status-notice">（七）“访问分部”（Visiting Division），指管制员在主分部以外申请提供管制服务的分部；</span>

<span class="regulation-status regulation-status-notice">（八）“分部成员”，指以该分部为主分部的管制员；</span>

<span class="regulation-status regulation-status-notice">（九）“分部主管”，指负责主持分部管理及日常运行事务的人员；</span>

<span class="regulation-status regulation-status-notice">（十）“管制区域”，指由席位负责提供管制服务的地理范围。</span>

**第五条（服务定位）**　CAN 是一个非专业的平台，平台注重飞行员与管制员的连飞体验。管制员的任务是为机组提供管制服务，而不是追求权威。

## <span class="regulation-status regulation-status-notice">第二章　分部设立、管理与运行</span>

<span class="regulation-status regulation-status-notice">**第六条（分部与地区）**　每个分部应当对应一个明确的地区，并负责该地区内相关管制区域、席位及管制运行事务的管理。分部对应的地区、主管及席位范围，以平台公布的[管制员名册](https://ceruleanavi.net/roster)及相关运行资料为准。</span>

<span class="regulation-status regulation-status-notice">管制员的分部关系分为主分部（Home Division）与访问分部（Visiting Division）。每名管制员应当有一个主分部，并可以按照本准则及相关分部规定申请加入一个或者多个访问分部。</span>

<span class="regulation-status regulation-status-notice">**第七条（创建申请）**　任何人均可以向管理组提交开设新分部的申请。申请应当至少说明拟设分部的名称、对应地区、拟管理的管制区域及席位、设立理由和基础运行计划。</span>

<span class="regulation-status regulation-status-notice">管理组负责审核新分部申请，并可以要求申请人补充资料或者调整拟管理的地区与范围。未经管理组批准，不得以 CAN 分部名义开展招募、训练、考核、授权或者其他管理活动。</span>

<span class="regulation-status regulation-status-notice">**第八条（设立与首届主管）**　新分部的创建申请经管理组批准后，分部正式设立，申请人自动成为该分部第一届分部主管。</span>

<span class="regulation-status regulation-status-notice">申请人有两人以上的，应当在申请中共同指定一人担任第一届分部主管；未能共同指定的，由管理组在申请人中确定。</span>

<span class="regulation-status regulation-status-notice">**第九条（主管选举与管理人员罢免）**　第一届之后的分部主管，由对应分部成员选举产生。分部主管选举应当遵循公开、公平和可核验的原则，具体选举程序由分部制定并事先向全体分部成员公布。</span>

<span class="regulation-status regulation-status-notice">选举结果应当及时向管理组报备，由管理组据此更新管制员名册。分部主管依照已公布的选举结果就任，管理组的报备与名册更新不改变分部成员的选举结果。管制员不得仅以访问分部成员身份参与分部主管选举，但该管制员同时以该分部为主分部的除外。</span>

<span class="regulation-status regulation-status-notice">管理组收到六名以上不同人员针对同一分部管理人员提交的投诉，经调查确认投诉属实的，应当考虑启动对该管理人员的罢免程序。该分部的访问分部成员提交的投诉，计入前述投诉人数。本款所称分部管理人员，包括分部主管及分部内部其他管理人员。</span>

<span class="regulation-status regulation-status-notice">罢免应当由以该分部为主分部的全体成员投票决定。参与投票的成员达到前述成员总数三分之二以上的，该次投票有效；在有效投票中，超过半数的票数支持罢免的，管理组应当罢免该管理人员。仅以访问分部成员身份加入该分部的管制员不得参与罢免投票，也不计入本款所称成员总数；该管制员同时以该分部为主分部的除外。</span>

<span class="regulation-status regulation-status-notice">**第十条（主管职责）**　分部主管负责分部内部的管理与基础运行，其职责包括：</span>

<span class="regulation-status regulation-status-notice">（一）组织和协调分部负责地区内的日常管制运行；</span>

<span class="regulation-status regulation-status-notice">（二）任命分部内部管理人员、教员及其他必要职务，并明确其职责；</span>

<span class="regulation-status regulation-status-notice">（三）组织分部管制员的招募、训练和考核；</span>

<span class="regulation-status regulation-status-notice">（四）依据训练与考核结果，决定分部管制员的权限授予、晋升、降级及针对性训练；</span>

<span class="regulation-status regulation-status-notice">（五）制定并公布本分部的席位要求、训练标准、考核标准和基础运行规则；</span>

<span class="regulation-status regulation-status-notice">（六）维护分部成员、权限、任命及训练记录，并依照管理组要求完成报备；</span>

<span class="regulation-status regulation-status-notice">（七）代表分部与管理组及其他分部进行协调。</span>

<span class="regulation-status regulation-status-notice">分部主管行使职权时应当遵守本准则与《平台总则》，不得授予超出平台席位阶梯的权限，不得免除成员应当完成的训练或者考核。</span>

<span class="regulation-status regulation-status-notice">**第十一条（基础运行）**　分部应当维持基本、持续且可以追溯的运行管理，及时公布并更新席位、频率、管制范围、训练要求、考核标准及内部任命等信息。</span>

<span class="regulation-status regulation-status-notice">分部制定的内部规则不得与本准则或者《平台总则》冲突，不得不合理限制分部成员接受训练、参加考核、申请晋升或者参与主管选举的权利。涉及其他分部负责地区或者共同管制边界的，应当与相关分部完成协调。</span>

<span class="regulation-status regulation-status-notice">**第十二条（分部公示）**　分部应当通过平台或者管理组认可的公开渠道发布分部公示，确保分部成员及相关管制员可以及时查阅。</span>

<span class="regulation-status regulation-status-notice">下列事项应当进行公示：</span>

<span class="regulation-status regulation-status-notice">（一）分部主管选举的安排、候选人、程序及结果；</span>

<span class="regulation-status regulation-status-notice">（二）分部内部管理人员、教员及其他职务的任命、调整与解除；</span>

<span class="regulation-status regulation-status-notice">（三）席位、频率、管制范围及基础运行规则的制定或者变更；</span>

<span class="regulation-status regulation-status-notice">（四）训练要求、考核标准、权限晋升要求及访问资格规则的制定或者变更；</span>

<span class="regulation-status regulation-status-notice">（五）其他可能影响分部成员权利、管制权限或者日常运行的重要事项。</span>

<span class="regulation-status regulation-status-notice">公示应当载明发布主体、主要内容、发布日期和生效日期。内容发生变更或者失效的，分部应当及时更新，并保留必要的历史记录以供查证；涉及个人隐私、考试内容或者其他不宜公开的信息，可以对相关内容作适当隐去。</span>

<span class="regulation-status regulation-status-notice">**第十三条（主分部）**　主分部负责所属管制员的招募、训练、考核、权限授予、晋升与日常管理。管制员取得的基础席位等级与管制权限，以主分部完成的训练、考核和授权为准。</span>

<span class="regulation-status regulation-status-notice">**第十四条（访问分部）**　管制员拟在主分部以外、已设有分部的地区提供管制服务时，应当依照对应访问分部的规定取得访问资格，并遵守该访问分部公布的本地运行要求、席位限制及协调安排。</span>

<span class="regulation-status regulation-status-notice">访问分部可以根据本地运行需要进行必要的知识确认、熟悉训练或者考核，但不得据此变更管制员由主分部授予的基础席位等级与权限。</span>

<span class="regulation-status regulation-status-notice">**第十五条（未设分部的管制区域）**　管制区域没有对应分部的，管制员在该区域提供管制服务时，按照其主分部授予的权限执行，无需取得访问分部资格。</span>

<span class="regulation-status regulation-status-notice">管制员仍不得占用高于其主分部所授权限的席位。该区域的席位、频率、管制范围及临时运行安排，由管理组公布或者指定分部代为协调。</span>

## 第三章　资格与申请

**第十六条（申请条件）**　申请成为管制员的，应当具备一定的飞行知识。

平台建议申请者的连飞时长达到 50 小时以上。本款为建议，不作为受理申请的硬性条件。

申请的审核参考申请者的信用记录，见《平台总则》第三十六条。

<span class="regulation-status regulation-status-notice">**第十七条（受理）**　管制员申请由申请者拟加入的主分部主管受理。</span>

分部的划分及各分部的主管，以平台公布的[管制员名册](https://ceruleanavi.net/roster)为准。申请者应当依照名册确定对应分部的主管，并向其提交申请。

名册中未列明主管的分部，或者无法确定对应分部的，向平台主管 简约（CID 1000）提交申请，[j.h.liang@jianyuelab.co](mailto:j.h.liang@jianyuelab.co)。

<span class="regulation-status regulation-status-notice">本准则规定由分部主管受理的申请，包括管制员申请、访问分部申请及其他申请，均适用下列处理时限：</span>

<span class="regulation-status regulation-status-notice">（一）分部主管收到申请后，应当在 72 小时内回复申请人并确认已经收到申请；</span>

<span class="regulation-status regulation-status-notice">（二）分部主管应当自收到申请之日起 7 日内，向申请人告知处理结果及下一步安排；</span>

<span class="regulation-status regulation-status-notice">（三）申请提交后超过 72 小时，分部主管仍未作任何回应的，申请人可以向管理组成员提交该申请，请求管理组介入或者代为处理。</span>

## 第四章　席位与权限

**第十八条（席位阶梯）**　席位由低到高依次为：

（一）OBS　观察员，不提供管制服务；

（二）DEL　放行；

（三）GND　地面；

（四）TWR　塔台；

（五）APP　进近；

（六）CTR　区域。

各席位的代码、频率与管辖范围由分部结合实际运行情况公布，并报管理组备案。

**第十九条（权限范围）**　管制员只能占用其权限范围内及以下的席位，不得提供超出权限的管制服务。

**第二十条（向下兼容）**　管制员上线较高权限席位而下级席位无人在线的，应尽可能向下兼容，为下级区域提供管制服务。

<span class="regulation-status regulation-status-notice">**第二十一条（延展管制范围）**　管制员在上线席位时，可以通过在 `ATC info` 中添加 `Extending` 信息，延展至其他同等级的席位或者管制范围。延展只能发生在同一席位等级之间；例如，TWR 管制员只能 `Extending` 其他 TWR 席位，不得延展 DEL、GND、APP 或 CTR 等其他等级的席位。</span>

<span class="regulation-status regulation-status-notice">`Extending` 信息应当明确标注所延展的席位或者管制范围，并在实际开始提供延展范围内的管制服务前完成发布。延展范围不得超出管制员的权限；如有其他管制员在线，管制员应当事先完成协调。停止延展时，应当及时移除或者更新 `Extending` 信息，并完成必要的管制移交。</span>

<span class="regulation-status regulation-status-notice">管制员延展管制范围时，还应当遵守下列规定：</span>

<span class="regulation-status regulation-status-notice">（一）管制范围内同时接受管制服务的机组达到 5 架时，管制员应当根据自身精力、工作负荷及运行情况，考虑缩小管制范围；管制员同时具有教员身份的，前述数量为 10 架；</span>

<span class="regulation-status regulation-status-notice">（二）处于实习期的管制员不得延展管制范围；</span>

<span class="regulation-status regulation-status-notice">（三）活动期间需要延展管制范围的，应当事先与管理组协商并取得同意；</span>

<span class="regulation-status regulation-status-notice">（四）管制范围的延展不得跨越国界；事先取得对应分部主管或者管理组许可的除外。</span>

**第二十二条（降级）**　有机组反馈管制员在管制中缺乏专业性或者必要能力的，平台核实后可以将其暂时降级为低一级权限，并要求其进行针对性训练；经平台认可达标后，重新授予相应权限。

<span class="regulation-status regulation-status-notice">训练的期限由该管制员主分部的主管或者责任教员确定，并告知本人。</span>

## 第五章　基本职责

**第二十三条（遵守规章）**　管制员提供管制服务时，应当遵守[《平台总则》](/zh_CN/regulation)与本准则的有关规定。

**第二十四条（冲突处理）**　出现冲突时，管制员应当冷静应对，平和面对机组，解答机组疑惑。

**第二十五条（服务边界）**　管制员仅提供管制服务，机长为航空器的第一决策人。管制员有责任全力为机组提供服务，但不得代替机长作出决策。

**第二十六条（开席协调）**　管制员在准备连线前，应当与其他已在线的管制员协调管制区域的划分与移交等事宜。

**第二十七条（流量控制）**　必要时，管制员应当控制场面交通流量。

**第二十八条（席位切换）**　管制范围内有机组的，管制员不得频繁切换管制席位，一小时内切换管制席位不得超过 3 次。

切换管制席位时，必须相应更换频率。

**第二十九条（高压时段）**　在密集时段，例如大型活动开始后的一段时间内，机组可能集中申请放行。面对大量机组的催促与抢麦，管制员应当保持良好的心态、友善的态度与高效的工作，在高压环境下做到心态与工作的平衡。

## 第六章　服务态度与纪律

**第三十条（态度要求）**　管制员应当友善对待机组与其他管制员。

机组遇到困难或者出现错误时，管制员应当以友善的态度帮助其解决问题并加以指导，**不得嘲讽或者指责**。

**第三十一条（禁止追求权威）**　平台不欢迎以指挥他人、满足权威感为目的加入管制团队的申请者。

**第三十二条（态度监督）**　平台在运行的全过程对管制员的态度进行监督，并对态度问题保持高压态势。

**第三十三条（态度问题的处理）**　管制员对机组或者其他管制员态度恶劣，经核实属实的，依照下列规定处理：

（一）处于实习期的管制员，警告一次；再次发生的，直接取消其管制员资格，并永久禁止其重新申请 CAN 的管制员资格；

<span class="regulation-status regulation-status-notice">（二）已过实习期的管制员，警告一次；再次发生的，降级为 OBS，并在一定期限内禁止其重新申请管制员资格；该期限由其主分部主管或者责任教员确定，并告知本人。</span>

**第三十四条（申诉）**　管制员对依照第二十二条、第三十三条作出的处理有异议的，可以依照[《平台总则》](/zh_CN/regulation)第三十八条以电子邮件提交反馈，由管理组按照该章规定的程序审理。

## 第七章　附则

<span class="regulation-status regulation-status-notice">**第三十五条（联系方式）**　本准则涉及的申请、训练与考核事务，通过第十七条确定的主分部主管办理。</span>

对本准则的疑问、建议与反馈，依照[《平台总则》](/zh_CN/regulation)第三十八条，以电子邮件发送至 [feedback@ceruleanavi.net](mailto:feedback@ceruleanavi.net)。

**第三十六条（解释）**　本准则由 Cerulean Aviation Network 管理组负责解释。

**第三十七条（施行）**　本准则的修改、公示与施行，参照[《平台总则》](/zh_CN/regulation)第四十九条的规定办理。
