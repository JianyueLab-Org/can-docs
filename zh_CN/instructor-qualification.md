# <span class="regulation-status regulation-status-pending">教员资格认定办法</span>

## <span class="regulation-status regulation-status-pending">第一章　总则</span>

<span class="regulation-status regulation-status-pending">**第一条（目的）**　为规范 CAN 天蓝模拟飞行平台 PRC 本部空中交通管制部门教员的选拔、培训、考核和任命工作，建立公平、透明、可追溯的教员资格认定机制，制定本办法。</span>

<span class="regulation-status regulation-status-pending">**第二条（适用范围）**　本办法适用于：</span>

<span class="regulation-status regulation-status-pending">（一）PRC 本部空中交通管制部门教员的申请、见习、考核和任命；</span>

<span class="regulation-status regulation-status-pending">（二）I1、I2、I3 各级教员资格的首次认定和晋级认定；</span>

<span class="regulation-status regulation-status-pending">（三）教员资格恢复、重新认定及相关复核事项。</span>

<span class="regulation-status regulation-status-pending">**第三条（基本原则）**　教员资格认定遵循以下原则：</span>

<span class="regulation-status regulation-status-pending">（一）能力导向原则；</span>

<span class="regulation-status regulation-status-pending">（二）证据充分原则；</span>

<span class="regulation-status regulation-status-pending">（三）培训与考核分离原则；</span>

<span class="regulation-status regulation-status-pending">（四）利益冲突回避原则；</span>

<span class="regulation-status regulation-status-pending">（五）过程公开、结果可复核原则；</span>

<span class="regulation-status regulation-status-pending">（六）业务能力与教学能力分别评价原则。</span>

<span class="regulation-status regulation-status-pending">本办法所认定的教员资格，仅代表申请人具备在本平台指定范围内开展模拟管制培训的资格，</span>

## <span class="regulation-status regulation-status-pending">第二章　术语和角色定义</span>

<span class="regulation-status regulation-status-pending">**第五条（术语定义）**　本办法中：</span>

<span class="regulation-status regulation-status-pending">（一）**学员**：正在接受本部门管制技能、运行规则或席位能力培训的人员。</span>

<span class="regulation-status regulation-status-pending">（二）**见习教员**：已通过初步审核，正在监督下参与教学但尚未取得独立执教资格的人员。</span>

<span class="regulation-status regulation-status-pending">（三）**正式教员**：经规定程序认定并任命，可在授权范围内独立开展培训的人员。</span>

<span class="regulation-status regulation-status-pending">（四）**教员主管**：负责教员队伍管理、教学质量监督和教员资格审核的管理人员。</span>

<span class="regulation-status regulation-status-pending">（五）**有效培训记录**：包含培训时间、席位、训练目标、主要表现、问题记录和后续建议的完整记录。</span>

<span class="regulation-status regulation-status-pending">（六）**关键不合格项**：可能直接导致运行风险、考核失真、记录失实或严重破坏培训秩序的行为。</span>

## <span class="regulation-status regulation-status-pending">第三章　教员等级与岗位定位</span>

<span class="regulation-status regulation-status-pending">**第六条（教员岗位定位）**　教员是本部门承担管制培训、能力指导、运行复盘和学员评价工作的专业人员。</span>

<span class="regulation-status regulation-status-pending">教员的核心职责是：</span>

<span class="regulation-status regulation-status-pending">（一）帮助学员建立正确的管制思维和运行习惯；</span>

<span class="regulation-status regulation-status-pending">（二）根据统一标准实施训练；</span>

<span class="regulation-status regulation-status-pending">（三）及时识别并制止可能造成运行风险的行为；</span>

<span class="regulation-status regulation-status-pending">（四）对学员表现提供客观、具体、可执行的反馈；</span>

<span class="regulation-status regulation-status-pending">（五）形成完整、真实、可追溯的培训记录。</span>

<span class="regulation-status regulation-status-pending">**第八条（教员资格与席位权限分离）**　取得 I1、I2 或 I3 教员资格，不代表自动获得所有席位的教学权限。</span>

<span class="regulation-status regulation-status-pending">教员只能在以下范围内执教：</span>

<span class="regulation-status regulation-status-pending">（一）自身已具备相应席位能力；</span>

<span class="regulation-status regulation-status-pending">（二）已通过对应席位的教学授权；</span>

<span class="regulation-status regulation-status-pending">（三）处于有效教员状态；</span>

<span class="regulation-status regulation-status-pending">（四）未被限制、暂停或取消相关权限。</span>

## <span class="regulation-status regulation-status-pending">第四章　申请条件</span>

<span class="regulation-status regulation-status-pending">**第九条（基本申请条件）**　申请教员资格的人员应同时满足：</span>

<span class="regulation-status regulation-status-pending">（一）为 CAN 天蓝模拟飞行平台 PRC 本部正式成员或为访问分部成员，且已在相应的主分部取得教员权限；</span>

<span class="regulation-status regulation-status-pending">（二）已取得 C2 及以上管制等级的席位资格；</span>

<span class="regulation-status regulation-status-pending">（三）熟悉现行管制、运行、培训要求和平台规则；</span>

<span class="regulation-status regulation-status-pending">（四）具备清晰说明管制依据、风险判断和操作逻辑的能力；</span>

<span class="regulation-status regulation-status-pending">（五）最近 12 月内不存在严重违规，轻微违规与严重违规由管理组解释；</span>

<span class="regulation-status regulation-status-pending">（六）能够按照要求参加理论考试、试教和见习；</span>

<span class="regulation-status regulation-status-pending">（七）接受其他教员的记录和复核；</span>

<span class="regulation-status regulation-status-pending">（八）不存在影响公正教学的现实或平台内部冲突历史；</span>

<span class="regulation-status regulation-status-pending">（九）至少在本部拥有 10 小时的管制员时长；</span>

<span class="regulation-status regulation-status-pending">（十）至少参与过 3 次本部（包括本部和其他分部）组织的专业活动。</span>

<span class="regulation-status regulation-status-pending">**第十条（有效业务能力证明）**　由于本部门目前没有最低值班时长要求，申请人应向本部相关管理员和教员证明近期业务能力。需要满足的条件如下：</span>

<span class="regulation-status regulation-status-pending">**总管制小时数 + 引荐教员数 × 30 ≥ 100**</span>

<span class="regulation-status regulation-status-pending">引荐您的教员数量至少为 1，不能为 0。</span>

<span class="regulation-status regulation-status-pending">第九条所有条款均优先于此条，特别需要说明的是，教员的引荐不能免除第九条的 10 小时管制时长要求。</span>

::: tip <span class="regulation-status regulation-status-pending">以下内容是对第十条的举例解释说明</span>
<span class="regulation-status regulation-status-pending">若您在平台（本部）有 54 小时的管制时长，则您需要有两位教员向本部引荐您，方可通过业务能力证明（54 + 2 × 30 ≥ 100）。</span>

<span class="regulation-status regulation-status-pending">**若您的管制时长大于 70 小时，仅需一位教员引荐即可（∀x ≥ 70，x + 30 ≥ 100）。**</span>

<span class="regulation-status regulation-status-pending">即使您的管制时长大于 100，也需至少一位教员引荐。</span>
:::

<span class="regulation-status regulation-status-pending">**第十一条（不予受理情形）**　有下列情形之一的，原则上不予受理：</span>

<span class="regulation-status regulation-status-pending">（一）正处于暂停资格、限制权限或纪律调查期间；</span>

<span class="regulation-status regulation-status-pending">（二）曾伪造、篡改培训或考核记录；</span>

<span class="regulation-status regulation-status-pending">（三）曾泄露考试内容或内部考核材料；</span>

<span class="regulation-status regulation-status-pending">（四）曾利用教员、考官或管理身份谋取不当利益；</span>

<span class="regulation-status regulation-status-pending">（五）存在尚未解决的重大冲突；</span>

<span class="regulation-status regulation-status-pending">（六）申请材料严重缺失或存在虚假陈述。</span>

## <span class="regulation-status regulation-status-pending">第五章　申请和审核流程</span>

<span class="regulation-status regulation-status-pending">**第十二条（申请材料及其格式）**　申请人应在申请前检查自身是否符合基本申请条件和有效业务能力证明，避免无效申请。</span>

<span class="regulation-status regulation-status-pending">申请人应提交下列材料：</span>

<span class="regulation-status regulation-status-pending">（一）现有管制等级和席位资格证明：您的基本信息，您管制等级的截图；</span>

<span class="regulation-status regulation-status-pending">（二）现有活动参与和管制时长证明：专业活动结算后，您获得积分的截图，以及您的管制员时长截图，需包含所有席位；</span>

<span class="regulation-status regulation-status-pending">（三）有效业务能力证明：引荐您的教员的基本信息。</span>

<span class="regulation-status regulation-status-pending">**第十三条（资格初审）**　教员主管负责资格初审，重点审核：</span>

<span class="regulation-status regulation-status-pending">（一）申请人是否符合基本条件；</span>

<span class="regulation-status regulation-status-pending">（二）申请人现有业务能力是否匹配教员职位；</span>

<span class="regulation-status regulation-status-pending">（三）申请材料是否完整、真实；</span>

<span class="regulation-status regulation-status-pending">（四）是否存在纪律问题；</span>

<span class="regulation-status regulation-status-pending">（五）是否具备进入见习阶段的条件；</span>

<span class="regulation-status regulation-status-pending">（六）引荐申请人的教员的意见。</span>

<span class="regulation-status regulation-status-pending">初审结果分为：</span>

- <span class="regulation-status regulation-status-pending">通过；</span>

- <span class="regulation-status regulation-status-pending">补充材料；</span>

- <span class="regulation-status regulation-status-pending">暂缓；</span>

- <span class="regulation-status regulation-status-pending">不予受理。</span>

<span class="regulation-status regulation-status-pending">**第十四条（实操考核）**　实操考核应通过模拟运行、案例处置、复盘讲解或监督值班等方式进行。</span>

<span class="regulation-status regulation-status-pending">考核内容包括：</span>

<span class="regulation-status regulation-status-pending">（一）席位准备和训练计划制定；</span>

<span class="regulation-status regulation-status-pending">（二）管制业务操作；</span>

<span class="regulation-status regulation-status-pending">（三）冲突识别和风险控制；</span>

<span class="regulation-status regulation-status-pending">（四）通信和指令表达；</span>

<span class="regulation-status regulation-status-pending">（五）工作负荷管理；</span>

<span class="regulation-status regulation-status-pending">（六）异常情况处理；</span>

<span class="regulation-status regulation-status-pending">（七）对学员错误的发现和纠正；</span>

<span class="regulation-status regulation-status-pending">（八）训练结束后的复盘和记录。</span>

<span class="regulation-status regulation-status-pending">出现以下情形之一的，实操考核不得判定为合格：</span>

<span class="regulation-status regulation-status-pending">（一）发生重大安全风险且未及时纠正；</span>

<span class="regulation-status regulation-status-pending">（二）明知操作违反 SOP 仍继续实施；</span>

<span class="regulation-status regulation-status-pending">（三）无法解释关键操作的依据；</span>

<span class="regulation-status regulation-status-pending">（四）在考核过程中对学员进行侮辱、威胁或打击报复；</span>

<span class="regulation-status regulation-status-pending">（五）管理组认定不得通过考核的。</span>

<span class="regulation-status regulation-status-pending">**第十六条（见习教员阶段）**　通过初审和理论考试后，申请人进入见习教员阶段。</span>

<span class="regulation-status regulation-status-pending">除教员主管另行批准外，见习阶段至少包括：</span>

<span class="regulation-status regulation-status-pending">（一）不少于 3 次正式教学观摩；</span>

<span class="regulation-status regulation-status-pending">（二）不少于 3 次协同教学；</span>

<span class="regulation-status regulation-status-pending">（三）不少于 2 次受监督试教；</span>

<span class="regulation-status regulation-status-pending">（四）至少完成一次培训复盘；</span>

<span class="regulation-status regulation-status-pending">（五）接受至少一名正式教员或考官的书面评价。</span>

<span class="regulation-status regulation-status-pending">见习教员不得：</span>

<span class="regulation-status regulation-status-pending">（一）独立判定学员通过或不通过；</span>

<span class="regulation-status regulation-status-pending">（二）独立实施正式资格考试；</span>

<span class="regulation-status regulation-status-pending">（三）修改学员成绩或考核结论；</span>

<span class="regulation-status regulation-status-pending">（四）代表部门实施纪律处分；</span>

<span class="regulation-status regulation-status-pending">（五）在未授权席位上独立执教。</span>

<span class="regulation-status regulation-status-pending">**第十七条（试教考核）**　试教应至少包含：</span>

<span class="regulation-status regulation-status-pending">（一）课前目标说明；</span>

<span class="regulation-status regulation-status-pending">（二）训练情景设置；</span>

<span class="regulation-status regulation-status-pending">（三）训练过程观察；</span>

<span class="regulation-status regulation-status-pending">（四）风险识别和必要干预；</span>

<span class="regulation-status regulation-status-pending">（五）训练后复盘。</span>

<span class="regulation-status regulation-status-pending">试教考核由至少一名正式教员或经批准的高级教员实施。申请人的直接指导教员可以提供意见，但原则上不得作为唯一评审人。</span>

<span class="regulation-status regulation-status-pending">**第十八条（正式任命条件）**　申请人同时满足以下条件后，方可正式任命：</span>

<span class="regulation-status regulation-status-pending">（一）通过资格初审；</span>

<span class="regulation-status regulation-status-pending">（二）理论考试关键项目全部合格；</span>

<span class="regulation-status regulation-status-pending">（三）实操考核无关键不合格项；</span>

<span class="regulation-status regulation-status-pending">（四）完成规定的见习和试教要求；</span>

<span class="regulation-status regulation-status-pending">（五）培训记录完整；</span>

<span class="regulation-status regulation-status-pending">（六）无正在处理的严重违规；</span>

<span class="regulation-status regulation-status-pending">（七）经教员主管审核。</span>

<span class="regulation-status regulation-status-pending">满足以上条件后，教员由部门主管或授权负责人正式任命。</span>

<span class="regulation-status regulation-status-pending">**第十九条（资格有效期）**　教员资格原则上有效期为 12 个月，但与[第二部分第十五条](/zh_CN/instructor-management)冲突时，按照第二部分第十五条执行。</span>
