# 如何成为管制员

## 前言

本文说明在 Cerulean Aviation Network（CAN）申请、训练并取得管制权限的一般步骤。

CAN 是非专业的模拟飞行网络，管制培训相对宽松，更看重热情、耐心和友善，不要求申请者一开始就具备专业管制能力。本文是给申请者看的路径说明，**不是规章**：资格、训练、考核和纪律以[《CAN 管制员准则》](/zh_CN/atc)为准，连线时还须遵守[《平台总则》](/zh_CN/regulation)。各分部的课表、考核方式和开席条件由该分部公布，本文只写全网共通的部分。

## 这条路适不适合你

管制员的任务是为机组提供服务，不是追求权威。平台不欢迎以指挥他人、满足权威感为目的加入的申请。机组遇到困难或者出错时，应当友善地帮助和指导，不得嘲讽或者指责。

申请前建议先作为飞行员连线，熟悉频率、指令和基本飞行知识。准则要求申请者具备一定的飞行知识，并建议连飞时长达到 50 小时以上；这是建议，不是受理申请的硬性条件。审核时会参考信用记录。

旁听培训不等于已经成为管制员，也不等于取得任何席位权限。想先看看课是什么样，可以依照[《培训旁听守则》](/zh_CN/training-observer)向教员申请旁听。

## 路径概览

1. 选定准备长期加入的**主分部**。
2. 向该分部主管提交管制员申请。
3. 按主分部安排完成训练与考核。
4. 取得权限后进入实习期，再独立开席。

之后的晋升仍由主分部负责。想到其他已设分部的地区开席，要另外申请访问分部资格。

## 第一步：选定主分部

每名管制员应当有一个主分部（Home Division）。主分部负责你的招募、训练、考核、权限授予、晋升和日常管理；你取得的基础席位等级与管制权限，以主分部完成的训练、考核和授权为准。

分部对应的地区、主管和席位范围，以平台公布的[管制员名册](https://ceruleanavi.net/roster)为准。目前平台设有大陆、香港、日本、美国、台湾等分部，组织关系见《平台总则》第四十七条。选一个你主要想提供管制服务、也方便参加训练的地区作为主分部。

还没有对应分部的管制区域，开席时按主分部授予的权限执行，不必先取得访问资格，但仍不得占用高于该权限的席位。

## 第二步：提交申请

管制员申请由你拟加入的主分部主管受理。请按名册找到对应主管，并按该分部公示的方式提交。申请、训练与考核**不走**总则第三十八条的反馈邮箱，那条通道只处理建议和投诉。

名册中未列明主管，或者无法确定对应分部的，向平台主管 简约（CID 1000）提交申请：[j.h.liang@jianyuelab.co](mailto:j.h.liang@jianyuelab.co)。

申请里建议写清：

- 你的 CAN ID 和注册邮箱
- 拟加入的主分部
- 飞行经历（连飞时长、常用机型或机场即可）
- 既往管制经验（如有）
- 为什么想在 CAN 做管制员

分部主管收到申请后，应当在 72 小时内确认收件，并在 7 日内告知处理结果和下一步安排。提交后超过 72 小时仍没有任何回应的，可以向管理组成员提交该申请，请求管理组介入或者代为处理。

各分部的选拔方式不完全相同。有的分部会安排面试，确认协作态度、责任感和训练适性；具体以该分部公布的规则为准。分部规则在[管制员中心](https://controller.ceruleanavi.net)查阅，登录后可看各分部的现行文本。

## 第三步：训练与考核

申请通过后，训练、考核和授权由主分部的主管和教员安排。分部不得免除你应当完成的训练或者考核，也不得授予超出平台席位阶梯的权限。

席位由低到高依次为：

| 代码 | 席位 | 说明 |
| --- | --- | --- |
| OBS | 观察员 | 不提供管制服务 |
| DEL | 放行 | |
| GND | 地面 | |
| TWR | 塔台 | |
| APP | 进近 | |
| CTR | 区域 | |

各席位的代码、频率与管辖范围由分部公布。你只能占用权限范围内及以下的席位。上线较高权限席位而下级席位无人在线时，应尽可能向下兼容，为下级区域提供服务。

公开的培训资料在[考试中心的培训栏目](https://exam.ceruleanavi.net/training)。目前并非每个分部都已发布完整课表；没有公开教材的分部，以主管或教员当场安排的内容为准。教材、分部规则和《平台总则》不一致时，以总则为准，其次是准则和该分部已经公布的规则。

## 第四步：实习与开席

通过考核并获得权限后，会有一段时间的实习期。期限由主分部主管或者责任教员确定，并告知本人。实习期内不得延展管制范围；态度问题的处理也更严：实习期警告一次，再次发生将取消资格并永久禁止重新申请。

独立开席前，通常需要准备：

- 管制客户端：按主分部要求安装。常见的是 EuroScope（配合本网络的扇区文件）或者 CRC
- 语音客户端：[Audio for CAN](https://ceruleanavi.net/downloads)（连线时的陆空通话）
- 部分面试和培训还会用到 TeamSpeak，以教员通知为准
- 现行航图、分部运行资料，以及该席位的频率、管制范围

客户端和语音软件可在主站[下载页](https://ceruleanavi.net/downloads)取得。开席前应当与已经在线的管制员协调区域划分和移交；管制范围内有机组时，一小时内切换席位不得超过 3 次，切换时必须更换频率。

## 取得权限之后

晋升、降级和针对性训练仍由主分部办理。有机组反馈缺乏专业性或者必要能力、平台核实后，可以暂时降一级并要求补训。

想到主分部以外、已设有分部的地区开席，须依照该访问分部的规定取得访问资格，并遵守其本地运行要求。访问分部可以安排必要的知识确认、熟悉训练或者考核，但不得据此变更主分部授予的基础席位等级与权限。

延展（`Extending`）只能发生在同一席位等级之间，且不得超出权限。实习期、活动期间和跨国延展另有限制，见准则第二十一条。
