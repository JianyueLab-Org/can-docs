# <span class="regulation-status regulation-status-pending">等级定义</span>

## <span class="regulation-status regulation-status-pending">等级与席位权限对照</span>

| <span class="regulation-status regulation-status-pending">等级</span> | <span class="regulation-status regulation-status-pending">定位</span> | <span class="regulation-status regulation-status-pending">席位权限</span> |
| --- | --- | --- |
| <span class="regulation-status regulation-status-pending">S1</span> | <span class="regulation-status regulation-status-pending">实习管制学员</span> | <span class="regulation-status regulation-status-pending">需在监管条件可以进行地面，放行席位的管制。</span> |
| <span class="regulation-status regulation-status-pending">S2</span> | <span class="regulation-status regulation-status-pending">管制学员</span> | <span class="regulation-status regulation-status-pending">可以独立进行地面，放行席位的管制，但需要在监管条件下可以进行塔台席位的管制。</span> |
| <span class="regulation-status regulation-status-pending">S3</span> | <span class="regulation-status regulation-status-pending">终端管制学员</span> | <span class="regulation-status regulation-status-pending">可以进行塔台及以下的席位独立管制，但需要在监管情况下可以进行终端进近席位的管制。</span> |
| <span class="regulation-status regulation-status-pending">C1</span> | <span class="regulation-status regulation-status-pending">实习区域管制学员</span> | <span class="regulation-status regulation-status-pending">可以进行进近及以下席位的管制，需要在监管情况下进行终端区域的管制。</span> |
| <span class="regulation-status regulation-status-pending">C2</span> | <span class="regulation-status regulation-status-pending">实习区域管制员</span> | <span class="regulation-status regulation-status-pending">可以进行区域管制，在监管情况下施行 ADS-B 管制。</span> |
| <span class="regulation-status regulation-status-pending">C3</span> | <span class="regulation-status regulation-status-pending">区域管制员</span> | <span class="regulation-status regulation-status-pending">可以进行终端及以下的所有管制。</span> |
| <span class="regulation-status regulation-status-pending">I1</span> | <span class="regulation-status regulation-status-pending">实习塔台管制教员</span> | <span class="regulation-status regulation-status-pending">可以在有同级或更高级别教员参与下进行塔台及以下的管制教学活动。</span> |
| <span class="regulation-status regulation-status-pending">I2</span> | <span class="regulation-status regulation-status-pending">塔台管制教员</span> | <span class="regulation-status regulation-status-pending">可以独立进行塔台席位以下教员管制活动。在有同级或更高级教员参与下可进行终端进近的管制教学。</span> |
| <span class="regulation-status regulation-status-pending">I3</span> | <span class="regulation-status regulation-status-pending">—</span> | <span class="regulation-status regulation-status-pending">可以独立进行终端及以下的管制教学活动。</span> |
