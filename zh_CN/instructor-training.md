# <span class="regulation-status regulation-status-pending">教员培训与考核实施细则</span>

## <span class="regulation-status regulation-status-pending">第一章　培训基本要求</span>

<span class="regulation-status regulation-status-pending">**第一条（培训目标）**　教员培训应使学员能够：</span>

<span class="regulation-status regulation-status-pending">（一）理解相关席位的运行逻辑；</span>

<span class="regulation-status regulation-status-pending">（二）按照手册和标准完成管制操作；</span>

<span class="regulation-status regulation-status-pending">（三）识别冲突、风险和异常情况；</span>

<span class="regulation-status regulation-status-pending">（四）解释操作依据；</span>

<span class="regulation-status regulation-status-pending">（五）接受、理解并应用教员反馈；</span>

<span class="regulation-status regulation-status-pending">（六）在考核前达到相应等级要求。</span>

<span class="regulation-status regulation-status-pending">**第二条（培训时长）**　针对同一席位、等级或能力单元的正式培训累计时间不得少于 10 小时。</span>

<span class="regulation-status regulation-status-pending">有效培训时间不包括：</span>

<span class="regulation-status regulation-status-pending">（一）设备故障；</span>

<span class="regulation-status regulation-status-pending">（二）长时间等待；</span>

<span class="regulation-status regulation-status-pending">（三）与训练无关的聊天；</span>

<span class="regulation-status regulation-status-pending">（四）无法完成训练目标的无效值班；</span>

<span class="regulation-status regulation-status-pending">（五）未经教员确认的个人练习时间。</span>

<span class="regulation-status regulation-status-pending">如需对已有经验进行折算，必须由教员主管批准并在培训记录中说明理由。</span>

## <span class="regulation-status regulation-status-pending">第二章　学员培训流程</span>

<span class="regulation-status regulation-status-pending">**第三条（培训阶段）**　学员培训原则上分为：</span>

<span class="regulation-status regulation-status-pending">（一）**入门阶段**：熟悉 EuroScope、席位功能、基本通信和软件环境；</span>

<span class="regulation-status regulation-status-pending">（二）**指导阶段**：在教员讲解和示范下完成基础任务；</span>

<span class="regulation-status regulation-status-pending">（三）**练习阶段**：由学员主导操作，教员进行监督和必要干预；</span>

<span class="regulation-status regulation-status-pending">（四）**综合阶段**：在较高工作负荷和复杂情景下完成训练；</span>

<span class="regulation-status regulation-status-pending">（五）**复盘阶段**：分析错误原因、运行影响和改进方法；</span>

<span class="regulation-status regulation-status-pending">（六）**考核准备阶段**：确认是否具备参加正式考核的条件。</span>

<span class="regulation-status regulation-status-pending">**第四条（课前要求）**　教员在培训开始前应：</span>

<span class="regulation-status regulation-status-pending">（一）查阅学员既往培训记录；</span>

<span class="regulation-status regulation-status-pending">（二）确认学员当前等级；</span>

<span class="regulation-status regulation-status-pending">（三）制定本次训练目标；</span>

<span class="regulation-status regulation-status-pending">（四）确认训练席位和情景；</span>

<span class="regulation-status regulation-status-pending">（五）说明训练重点及安全干预规则。</span>

<span class="regulation-status regulation-status-pending">**第五条（课中要求）**　教员在培训中应：</span>

<span class="regulation-status regulation-status-pending">（一）观察学员实际操作；</span>

<span class="regulation-status regulation-status-pending">（二）记录关键行为和错误；</span>

<span class="regulation-status regulation-status-pending">（三）对重大风险立即干预；</span>

<span class="regulation-status regulation-status-pending">（四）对一般错误优先采用提示和引导；</span>

<span class="regulation-status regulation-status-pending">（五）避免无必要地替代学员完成全部操作；</span>

<span class="regulation-status regulation-status-pending">（六）不在训练中随意改变考核标准。</span>

<span class="regulation-status regulation-status-pending">**第六条（课后要求）**　教员在培训结束后应：</span>

<span class="regulation-status regulation-status-pending">（一）总结学员完成情况；</span>

<span class="regulation-status regulation-status-pending">（二）指出不超过 3 项主要改进重点；</span>

<span class="regulation-status regulation-status-pending">（三）给出下一阶段训练建议；</span>

<span class="regulation-status regulation-status-pending">（四）完成培训记录；</span>

<span class="regulation-status regulation-status-pending">（五）在必要时向教员主管报告重大问题。</span>

## <span class="regulation-status regulation-status-pending">第三章　教员培训标准</span>

<span class="regulation-status regulation-status-pending">**第七条（教员培训内容）**　申请成为教员或晋级教员时，应至少接受以下内容培训：</span>

<span class="regulation-status regulation-status-pending">（一）教员岗位职责；</span>

<span class="regulation-status regulation-status-pending">（二）教学目标设计；</span>

<span class="regulation-status regulation-status-pending">（三）培训情景设计；</span>

<span class="regulation-status regulation-status-pending">（四）学员错误识别；</span>

<span class="regulation-status regulation-status-pending">（五）风险干预方法；</span>

<span class="regulation-status regulation-status-pending">（六）复盘与反馈方法；</span>

<span class="regulation-status regulation-status-pending">（七）评分和能力判定；</span>

<span class="regulation-status regulation-status-pending">（八）EuroScope 相关教学使用规范；</span>

<span class="regulation-status regulation-status-pending">（九）模拟平台社区沟通和冲突处理。</span>

<span class="regulation-status regulation-status-pending">**第八条（教学能力判断）**　教员不应仅因业务能力较强而自动获得教员资格。教学能力至少应通过以下证据证明：</span>

<span class="regulation-status regulation-status-pending">（一）能够制定明确训练目标；</span>

<span class="regulation-status regulation-status-pending">（二）能够发现学员关键问题；</span>

<span class="regulation-status regulation-status-pending">（三）能够区分知识错误、操作错误、判断错误和沟通错误；</span>

<span class="regulation-status regulation-status-pending">（四）能够控制训练风险；</span>

<span class="regulation-status regulation-status-pending">（五）能够用具体事实进行反馈；</span>

<span class="regulation-status regulation-status-pending">（六）能够形成完整培训记录；</span>

<span class="regulation-status regulation-status-pending">（七）能够根据学员水平调整教学方式。</span>

## <span class="regulation-status regulation-status-pending">第四章　考核实施</span>

<span class="regulation-status regulation-status-pending">**第九条（考核类型）**　本细则设置：</span>

<span class="regulation-status regulation-status-pending">（一）实操考核；</span>

<span class="regulation-status regulation-status-pending">（二）试教考核；</span>

<span class="regulation-status regulation-status-pending">（三）教员复核；</span>

<span class="regulation-status regulation-status-pending">（四）资格恢复考核；</span>

<span class="regulation-status regulation-status-pending">（五）特殊情况下的专项复核。</span>

<span class="regulation-status regulation-status-pending">**第十条（能力判定等级）**　考核采用以下三档判定：</span>

| <span class="regulation-status regulation-status-pending">**判定**</span> | <span class="regulation-status regulation-status-pending">**含义**</span> |
|:---------|:-----------------------------------------|
| <span class="regulation-status regulation-status-pending">合格</span> | <span class="regulation-status regulation-status-pending">已达到该项目要求，可在授权范围内独立完成</span> |
| <span class="regulation-status regulation-status-pending">需改进</span> | <span class="regulation-status regulation-status-pending">基本方向正确，但仍需补训、观察或重复考核</span> |
| <span class="regulation-status regulation-status-pending">不合格</span> | <span class="regulation-status regulation-status-pending">未达到要求，或出现关键风险、重大程序错误</span> |

<span class="regulation-status regulation-status-pending">不设置单一固定总分作为唯一结论，但所有关键项目必须合格。</span>

<span class="regulation-status regulation-status-pending">**第十一条（关键不合格项）**　出现以下情形之一，相关考核不得判定为合格：</span>

<span class="regulation-status regulation-status-pending">（一）未能识别或制止重大运行风险；</span>

<span class="regulation-status regulation-status-pending">（二）无法解释关键管制决策；</span>

<span class="regulation-status regulation-status-pending">（三）故意隐瞒问题；</span>

<span class="regulation-status regulation-status-pending">（四）对学员实施侮辱或报复；</span>

<span class="regulation-status regulation-status-pending">（五）擅自超越授权范围；</span>

<span class="regulation-status regulation-status-pending">（六）其他特殊情形。</span>

<span class="regulation-status regulation-status-pending">**第十二条（考核人员要求）**</span>

<span class="regulation-status regulation-status-pending">（一）考官应具有与考核项目相匹配的业务和考核授权；</span>

<span class="regulation-status regulation-status-pending">（二）考官不得在存在明显利益冲突时实施考核；</span>

<span class="regulation-status regulation-status-pending">（三）直接承担主要培训任务的教员，原则上不得作为唯一正式考官；</span>

<span class="regulation-status regulation-status-pending">（四）对有争议的结果，应增加一名复核人员；</span>

<span class="regulation-status regulation-status-pending">（五）考核过程应形成完整记录。</span>

## <span class="regulation-status regulation-status-pending">第五章　教学质量评价</span>

<span class="regulation-status regulation-status-pending">**第十三条（评价来源）**　教员教学质量可以通过以下证据评价：</span>

<span class="regulation-status regulation-status-pending">（一）教学记录；</span>

<span class="regulation-status regulation-status-pending">（二）受训学员反馈；</span>

<span class="regulation-status regulation-status-pending">（三）同行听课或观摩记录；</span>

<span class="regulation-status regulation-status-pending">（四）考核结果一致性；</span>

<span class="regulation-status regulation-status-pending">（五）教员主管抽查；</span>

<span class="regulation-status regulation-status-pending">（六）重大事件和复盘记录；</span>

<span class="regulation-status regulation-status-pending">（七）教员会议中的质量讨论；</span>

<span class="regulation-status regulation-status-pending">（八）教员本人提交的教学总结。</span>

<span class="regulation-status regulation-status-pending">**第十四条（质量问题分类）**　教学质量问题分为：</span>

<span class="regulation-status regulation-status-pending">（一）单次一般性问题；</span>

<span class="regulation-status regulation-status-pending">（二）重复性教学问题；</span>

<span class="regulation-status regulation-status-pending">（三）影响学员进度的问题；</span>

<span class="regulation-status regulation-status-pending">（四）影响考核公平的问题；</span>

<span class="regulation-status regulation-status-pending">（五）造成运行风险的严重问题。</span>

<span class="regulation-status regulation-status-pending">根据问题等级，可以采取提醒、复训、监督执教、限制权限或暂停执教等措施。</span>
