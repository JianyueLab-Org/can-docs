# <span class="regulation-status regulation-status-pending">教员管理条例</span>

## <span class="regulation-status regulation-status-pending">第一章　总则</span>

<span class="regulation-status regulation-status-pending">**第一条（制定目的）**　为规范教员日常教学、权限使用、行为管理和资格维护，保障学员接受公平、连续、统一的培训，制定本条例。</span>

<span class="regulation-status regulation-status-pending">**第二条（适用范围）**　本条例适用于：</span>

<span class="regulation-status regulation-status-pending">（一）正式教员；</span>

<span class="regulation-status regulation-status-pending">（二）见习教员；</span>

<span class="regulation-status regulation-status-pending">（三）参与教员管理、考核和培训质量监督的考官、区域负责人及主管人员。</span>

## <span class="regulation-status regulation-status-pending">第二章　教员权限与职责</span>

<span class="regulation-status regulation-status-pending">**第三条（教员可以行使的权限）**　在授权范围内，教员可以：</span>

<span class="regulation-status regulation-status-pending">（一）对学员进行理论讲解和实操指导；</span>

<span class="regulation-status regulation-status-pending">（二）指定训练目标和训练情景；</span>

<span class="regulation-status regulation-status-pending">（三）在训练过程中暂停明显不安全的操作；</span>

<span class="regulation-status regulation-status-pending">（四）要求学员对特定项目进行补训；</span>

<span class="regulation-status regulation-status-pending">（五）提交学员培训评价和晋级建议；</span>

<span class="regulation-status regulation-status-pending">（六）在授权范围内使用训练席位和教学资源。</span>

<span class="regulation-status regulation-status-pending">**第四条（教员不得行使的权限）**　教员不得擅自：</span>

<span class="regulation-status regulation-status-pending">（一）授予、取消或永久变更学员等级；</span>

<span class="regulation-status regulation-status-pending">（二）修改正式考核结果；</span>

<span class="regulation-status regulation-status-pending">（三）对其他教员实施纪律处分；</span>

<span class="regulation-status regulation-status-pending">（四）在未授权席位开展正式教学；</span>

<span class="regulation-status regulation-status-pending">（五）以个人意见替代部门正式制度；</span>

<span class="regulation-status regulation-status-pending">（六）因个人关系改变学员培训标准；</span>

<span class="regulation-status regulation-status-pending">（七）将个人争议带入培训、考核或评分。</span>

<span class="regulation-status regulation-status-pending">**第五条（教员日常职责）**　教员应当：</span>

<span class="regulation-status regulation-status-pending">（一）实施培训；</span>

<span class="regulation-status regulation-status-pending">（二）课前确认学员等级、培训目标和训练条件；</span>

<span class="regulation-status regulation-status-pending">（三）课中观察学员表现并及时干预关键风险；</span>

<span class="regulation-status regulation-status-pending">（四）课后提供具体反馈和改进建议；</span>

<span class="regulation-status regulation-status-pending">（五）按要求完成培训记录；</span>

<span class="regulation-status regulation-status-pending">（六）对重大问题和异常情况及时报告；</span>

<span class="regulation-status regulation-status-pending">（七）参加教员会议、复训和制度学习；</span>

<span class="regulation-status regulation-status-pending">（八）保护学员个人信息和培训资料；</span>

<span class="regulation-status regulation-status-pending">（九）在无法履职时及时取消或调整已确认的教学安排。</span>

## <span class="regulation-status regulation-status-pending">第三章　教学行为规范</span>

<span class="regulation-status regulation-status-pending">**第六条（教学沟通要求）**　教员应当：</span>

<span class="regulation-status regulation-status-pending">（一）使用清晰、准确、可理解的语言；</span>

<span class="regulation-status regulation-status-pending">（二）以事实和记录为基础进行评价；</span>

<span class="regulation-status regulation-status-pending">（三）说明问题发生的原因、影响和改进方向；</span>

<span class="regulation-status regulation-status-pending">（四）对不同水平的学员调整教学方式；</span>

<span class="regulation-status regulation-status-pending">（五）在公开频道避免不必要的羞辱性批评；</span>

<span class="regulation-status regulation-status-pending">（六）对学员提出的问题进行合理解释。</span>

<span class="regulation-status regulation-status-pending">教员不得使用侮辱、歧视、威胁、嘲讽或打击报复性语言。</span>

<span class="regulation-status regulation-status-pending">**第七条（反馈要求）**　反馈原则上应采用“事实—影响—建议”的结构。</span>

<span class="regulation-status regulation-status-pending">示例：</span>

> <span class="regulation-status regulation-status-pending">事实：学员在进近阶段连续两次未按要求建立间隔。</span>\
> <span class="regulation-status regulation-status-pending">影响：导致后机需要大幅减速，增加训练运行风险。</span>\
> <span class="regulation-status regulation-status-pending">建议：下一次训练重点观察排序、速度控制和提前量。</span>

<span class="regulation-status regulation-status-pending">反馈不得仅写“表现不好”“经验不足”“注意力不集中”等无法核实的结论。</span>

<span class="regulation-status regulation-status-pending">**第八条（统一标准要求）**　教员不得因以下因素改变培训标准：</span>

<span class="regulation-status regulation-status-pending">（一）私人关系；</span>

<span class="regulation-status regulation-status-pending">（二）群组或团队归属；</span>

<span class="regulation-status regulation-status-pending">（三）现实身份；</span>

<span class="regulation-status regulation-status-pending">（四）个人好恶；</span>

<span class="regulation-status regulation-status-pending">（五）历史争议；</span>

<span class="regulation-status regulation-status-pending">（六）学员是否活跃；</span>

<span class="regulation-status regulation-status-pending">（七）学员是否担任平台管理职务。</span>

## <span class="regulation-status regulation-status-pending">第四章　利益冲突与回避</span>

<span class="regulation-status regulation-status-pending">**第九条（应当回避的情形）**　出现以下情形时，教员应主动向教员主管报告并回避：</span>

<span class="regulation-status regulation-status-pending">（一）与学员存在尚未解决的私人争议；</span>

<span class="regulation-status regulation-status-pending">（二）教员可能因学员通过或不通过而获得直接利益；</span>

<span class="regulation-status regulation-status-pending">（三）教员参与了涉及该学员的调查或处罚；</span>

<span class="regulation-status regulation-status-pending">（四）教员本人是相关事件的直接当事人；</span>

<span class="regulation-status regulation-status-pending">（五）教员与学员存在明显的上下级、竞争或团队利益关系；</span>

<span class="regulation-status regulation-status-pending">（六）其他足以影响公正判断的情形。</span>

<span class="regulation-status regulation-status-pending">**第十条（回避处理）**　回避后，由教员主管指定其他具备相应授权的教员或考官接替。</span>

<span class="regulation-status regulation-status-pending">如因人员不足无法完全回避，应：</span>

<span class="regulation-status regulation-status-pending">（一）事先说明利益关系；</span>

<span class="regulation-status regulation-status-pending">（二）由另一名教员或考官进行复核；</span>

<span class="regulation-status regulation-status-pending">（三）不得由存在利益冲突的人员单独决定最终结果。</span>

## <span class="regulation-status regulation-status-pending">第五章　教学记录和档案管理</span>

<span class="regulation-status regulation-status-pending">**第十一条（记录内容）**　每次正式培训原则上应记录：</span>

<span class="regulation-status regulation-status-pending">（一）学员 CID 和当前等级；</span>

<span class="regulation-status regulation-status-pending">（二）教员 CID 和授权范围；</span>

<span class="regulation-status regulation-status-pending">（三）培训日期、起止时间和席位；</span>

<span class="regulation-status regulation-status-pending">（四）本次训练目标；</span>

<span class="regulation-status regulation-status-pending">（五）训练情景；</span>

<span class="regulation-status regulation-status-pending">（六）学员主要表现；</span>

<span class="regulation-status regulation-status-pending">（七）发现的问题和风险；</span>

<span class="regulation-status regulation-status-pending">（八）教员采取的干预措施；</span>

<span class="regulation-status regulation-status-pending">（九）下一步训练建议；</span>

<span class="regulation-status regulation-status-pending">（十）学员和教员确认信息。</span>

<span class="regulation-status regulation-status-pending">**第十二条（记录真实性）**　教员不得：</span>

<span class="regulation-status regulation-status-pending">（一）伪造培训时间；</span>

<span class="regulation-status regulation-status-pending">（二）代替他人填写记录；</span>

<span class="regulation-status regulation-status-pending">（三）隐瞒重大错误；</span>

<span class="regulation-status regulation-status-pending">（四）删除不利于本人或学员的事实；</span>

<span class="regulation-status regulation-status-pending">（五）在事后无说明地修改原始记录。</span>

<span class="regulation-status regulation-status-pending">如需修改，应保留原记录、修改时间、修改人和修改理由。</span>

<span class="regulation-status regulation-status-pending">**第十三条（档案权限）**　培训档案原则上由教员主管统一管理。</span>

<span class="regulation-status regulation-status-pending">可查阅人员包括：</span>

<span class="regulation-status regulation-status-pending">（一）相关学员本人；</span>

<span class="regulation-status regulation-status-pending">（二）承担该学员培训任务的教员；</span>

<span class="regulation-status regulation-status-pending">（三）考官；</span>

<span class="regulation-status regulation-status-pending">（四）教员主管；</span>

<span class="regulation-status regulation-status-pending">（五）部门主管；</span>

<span class="regulation-status regulation-status-pending">（六）经授权的调查或复核人员；</span>

<span class="regulation-status regulation-status-pending">（七）管理组成员。</span>

<span class="regulation-status regulation-status-pending">档案保存期限暂定为不少于 24 个月。</span>

## <span class="regulation-status regulation-status-pending">第六章　教员继续资格</span>

<span class="regulation-status regulation-status-pending">**第十四条（持续履职要求）**　教员应当：</span>

<span class="regulation-status regulation-status-pending">（一）按要求完成教学任务；</span>

<span class="regulation-status regulation-status-pending">（二）保持对管制手册和培训制度的了解；</span>

<span class="regulation-status regulation-status-pending">（三）参加制度更新学习；</span>

<span class="regulation-status regulation-status-pending">（四）接受教学质量抽查；</span>

<span class="regulation-status regulation-status-pending">（五）及时提交培训记录；</span>

<span class="regulation-status regulation-status-pending">（六）配合学员反馈和复盘；</span>

<span class="regulation-status regulation-status-pending">（七）在授权范围内持续保持业务能力。</span>

<span class="regulation-status regulation-status-pending">**第十五条（不活跃管理）**　连续 6 个月无有效教学记录的教员，教员主管可以将其状态调整为：</span>

- <span class="regulation-status regulation-status-pending">正常；</span>

- <span class="regulation-status regulation-status-pending">限制执教；</span>

- <span class="regulation-status regulation-status-pending">暂停执教；</span>

- <span class="regulation-status regulation-status-pending">待复核。</span>

<span class="regulation-status regulation-status-pending">恢复权限前，可以要求其完成：</span>

<span class="regulation-status regulation-status-pending">（一）一次业务能力复核；</span>

<span class="regulation-status regulation-status-pending">（二）一次受监督试教；</span>

<span class="regulation-status regulation-status-pending">（三）教员职责确认。</span>

## <span class="regulation-status regulation-status-pending">第七章　晋级、降级、暂停和取消资格</span>

<span class="regulation-status regulation-status-pending">**第十六条（教员晋级）**　教员晋级应根据以下证据综合判断：</span>

<span class="regulation-status regulation-status-pending">（一）已完成当前等级规定的教学任务；</span>

<span class="regulation-status regulation-status-pending">（二）具备更高等级所需的席位能力；</span>

<span class="regulation-status regulation-status-pending">（三）教学记录完整；</span>

<span class="regulation-status regulation-status-pending">（四）教学反馈不存在持续性严重问题；</span>

<span class="regulation-status regulation-status-pending">（五）通过对应等级的理论、实操或试教考核；</span>

<span class="regulation-status regulation-status-pending">（六）无尚未处理完毕的严重违规。</span>

<span class="regulation-status regulation-status-pending">**第十七条（限制执教）**　出现以下情形之一，可以限制教员部分权限：</span>

<span class="regulation-status regulation-status-pending">（一）某一席位能力出现持续性问题；</span>

<span class="regulation-status regulation-status-pending">（二）教学记录质量不符合要求；</span>

<span class="regulation-status regulation-status-pending">（三）学员反馈显示存在重复性教学缺陷；</span>

<span class="regulation-status regulation-status-pending">（四）教员长期未开展相关席位教学；</span>

<span class="regulation-status regulation-status-pending">（五）教员正在接受复训或质量观察。</span>

<span class="regulation-status regulation-status-pending">限制执教不等同于取消教员资格。</span>

<span class="regulation-status regulation-status-pending">**第十八条（暂停执教）**　出现以下情形之一，可以暂停教员全部或部分教学权限：</span>

<span class="regulation-status regulation-status-pending">（一）发生重大教学失误；</span>

<span class="regulation-status regulation-status-pending">（二）拒绝配合调查、复核或整改；</span>

<span class="regulation-status regulation-status-pending">（三）对学员实施侮辱、骚扰或打击报复或有其他重大态度问题；</span>

<span class="regulation-status regulation-status-pending">（四）在调查期间继续使用相关权限可能影响公平或安全。</span>

<span class="regulation-status regulation-status-pending">**第十九条（取消教员资格）**　出现以下情形之一，可以取消教员资格：</span>

<span class="regulation-status regulation-status-pending">（一）伪造考核结果或培训记录；</span>

<span class="regulation-status regulation-status-pending">（二）利用教员权限谋取私人利益；</span>

<span class="regulation-status regulation-status-pending">（三）故意隐瞒重大事件；</span>

<span class="regulation-status regulation-status-pending">（四）多次整改后仍持续严重违反制度；</span>

<span class="regulation-status regulation-status-pending">（五）实施严重侮辱、歧视、骚扰或报复行为或有其他重大态度问题；</span>

<span class="regulation-status regulation-status-pending">（六）其他足以使其不再适合担任教员的行为。</span>

## <span class="regulation-status regulation-status-pending">第八章　紧急临时授权</span>

<span class="regulation-status regulation-status-pending">**第二十条（临时授权适用情形）**　在正式教员临时不足、特殊活动、重大培训任务或其他确有必要的情况下，可以实施临时授权。</span>

<span class="regulation-status regulation-status-pending">**第二十一条（临时授权要求）**　临时授权必须：</span>

<span class="regulation-status regulation-status-pending">（一）明确授权人；</span>

<span class="regulation-status regulation-status-pending">（二）明确被授权人；</span>

<span class="regulation-status regulation-status-pending">（三）明确授权席位和事项；</span>

<span class="regulation-status regulation-status-pending">（四）明确授权起止时间；</span>

<span class="regulation-status regulation-status-pending">（五）明确监督教员；</span>

<span class="regulation-status regulation-status-pending">（六）形成书面或可追溯记录。</span>

<span class="regulation-status regulation-status-pending">临时授权不得超过 15 日，不得自动转化为正式教员资格。</span>

<span class="regulation-status regulation-status-pending">**第二十二条（临时授权限制）**　临时授权人员不得：</span>

<span class="regulation-status regulation-status-pending">（一）独立实施正式资格考试；</span>

<span class="regulation-status regulation-status-pending">（二）授予或取消正式等级；</span>

<span class="regulation-status regulation-status-pending">（三）处理本人涉及的争议；</span>

<span class="regulation-status regulation-status-pending">（四）对其他教员实施纪律处分；</span>

<span class="regulation-status regulation-status-pending">（五）超出书面授权范围执教。</span>

## <span class="regulation-status regulation-status-pending">第十章　制度解释和修订</span>

<span class="regulation-status regulation-status-pending">**第二十六条（解释权）**　本条例由 CAN PRC 分部管理组负责解释。</span>

<span class="regulation-status regulation-status-pending">**第二十七条（修订机制）**　出现以下情形时，应评估是否修订本条例：</span>

<span class="regulation-status regulation-status-pending">（一）席位体系或等级体系发生变化；</span>

<span class="regulation-status regulation-status-pending">（二）运行手册发生重大调整；</span>

<span class="regulation-status regulation-status-pending">（三）教学实践中发现制度漏洞；</span>

<span class="regulation-status regulation-status-pending">（四）申诉或复核中发现标准不一致；</span>

<span class="regulation-status regulation-status-pending">（五）平台软件或培训方式发生重大变化。</span>

<span class="regulation-status regulation-status-pending">**第二十八条（违规处理和申诉）**　教员或学员对培训、考核或处理结果有异议的，可以在结果公布后 7 日内以邮箱形式向分部管理提交书面申诉，且应带有相关证据。无法联系分部主管的，可联系管理组，由管理组代为转交。</span>

<span class="regulation-status regulation-status-pending">对分部主管的申诉处理结果有异议的，或教员或学员认为有必要的，按照[CAN 总则](/zh_CN/regulation) 第三十八条相关要求向 [feedback@ceruleanavi.net](mailto:feedback@ceruleanavi.net) 提交相关反馈，由管理组处理。</span>
