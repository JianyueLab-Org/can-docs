# Cerulean Aviation Network 隐私说明

本说明说明 CAN 如何处理成员的个人信息。它只约束本平台，不替代 JianyueLab 其它产品的政策。

CAN 由 JIANYUELAB LTD（“JianyueLab”）运营。控制者是该公司。隐私相关问询，按[《平台总则》](/zh_CN/regulation)第四十七条联系平台主管。

## 账号由本平台自行掌握

成员账号在本平台内注册、核验、使用、导出和关闭。账号不迁往 JianyueLab 的其它产品，也不交由第三方账号体系托管。

个人数据存放在 JianyueLab 的服务器和基础设施上，由本平台使用，不另交托管。验证邮箱、重置密码等邮件由 JianyueLab 自行运营的邮件服务发送，收件地址不交给第三方邮件服务商。

## 处理哪些信息

为提供连飞、管制、考试、飞行计划和网站登录，本平台处理：

- CAN ID、显示名称、电子邮箱
- 网站登录密码（加密保存）以及用于连线的网络口令
- 飞行与管制记录、飞行计划、考试成绩、活动报名、积分
- 成员在开发者中心登记的 OAuth 应用

这些信息保存在 JianyueLab 的服务器和基础设施上，用于履行与成员之间的服务，以及维护网络安全与运行秩序。

## Cookie

登录后，浏览器保存名为 `can_session` 的 Cookie，域名为 `.ceruleanavi.net`，供主站及其卫星站点识别已登录成员。该 Cookie 为登录所必需：不勾选保持登录时，关闭浏览器即失效；勾选后在浏览器中保留 30 天。本平台不使用广告或分析类 Cookie。

## 保存多久

| 数据 | 期限 |
| --- | --- |
| 登录会话（勾选保持登录） | 30 天 |
| 验证邮箱链接 | 24 小时 |
| 重置密码链接 | 1 小时 |
| 更换邮箱链接 | 2 小时 |
| OAuth 授权码 | 5 分钟 |
| OAuth 访问令牌 | 1 小时 |
| OAuth 刷新令牌 | 60 天未使用则失效 |
| 语音令牌 | 最长 10 分钟 |
| 公开航迹（按 CAN ID 查询） | 在线期间，及断线后约 3 小时 |
| 位置点（供航迹使用） | 72 小时 |
| 关闭后的账号行 | 1 年，随后删除 |

过期的验证链接、OAuth 授权码和令牌由小时任务删除。飞行与管制记录在账号存续期间保留，关闭账号时删除。

## 连飞时公开的信息

接入网络后，其它成员可以通过数据馈送和雷达看到呼号、CAN ID、客户端填报的姓名，以及模拟器中的位置。这是连飞本身的一部分，不是把账号交给第三方。

## 可选的外部绑定

下列绑定均非注册所必需，由成员自行决定，可随时在网站解除；关闭 CAN 账号时一并删除。

- **Discord / QQ**：只保存平台类型、平台用户 ID 与 CAN 账号的对应关系，用于机器人指令。
- **SimBrief**：只保存成员自行填写的 SimBrief Pilot ID，用于读取该成员已经存在于 SimBrief 的飞行计划。

对外接入可能经过 Cloudflare。航图、试题配图等对象文件可能存放在 Cloudflare 的对象存储中，其中不含账号或口令。

## 导出与关闭

成员可在网站「个人面板 → 账号」下载一份 JSON 导出，并关闭账号。关闭后立即无法登录。飞行记录、绑定和该成员登记的 OAuth 应用会立刻删除。账号行保留一年，期间同一邮箱与 CAN ID 不得再注册；一年届满后删除。无法登录时，可以通过邮件联系平台主管处理。详见[《平台总则》](/zh_CN/regulation)第四十七条。
