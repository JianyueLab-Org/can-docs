# 修订历史与公示信息

本页面记录 Cerulean Aviation Network 规章文件的修订、公示、施行及归档信息，便于用户查询条文变化和当前状态。

::: warning 说明
本页面用于汇总修订过程，不替代规章正文。修订内容、状态或者日期与规章正文中的说明不一致时，以对应规章正文及管理组正式公告为准。
:::

## 状态说明

- <span class="regulation-status regulation-status-pending">未施行</span>：修订尚未施行、暂缓施行或者施行日期尚未确定。
- <span class="regulation-status regulation-status-notice">公示中，未施行</span>：修订正在公示期内，公示期结束前不产生施行效力。
- <span class="regulation-status regulation-status-effective">已施行，公示中</span>：修订已经施行，但仍处于施行后的 30 天公示期。
- **已施行**：修订已经施行，且施行后的公示期已经结束。
- **已撤回**：修订提案已经撤回，不再进入施行程序。
- **已取代**：相关内容已经被后续版本或者修订取代，仅作历史记录。

颜色仅用于辅助识别。每项记录所列的文字状态、公示日期和施行日期为判断修订状态的主要依据。

## 记录字段

每项修订原则上记录以下信息：

| 字段 | 说明 |
| --- | --- |
| 修订编号 | 用于识别和引用该次修订的唯一编号 |
| 涉及文件 | 本次修订所影响的规章文件 |
| 修订摘要 | 主要新增、修改或者删除的内容 |
| 当前状态 | 未施行、公示中、已施行、已撤回或者已取代 |
| 公示日期 | 开始进行修改公示的日期；未确定时标记为“待确认” |
| 施行日期 | 修订开始产生效力的日期；未确定时标记为“待确认” |
| 相关信息 | 正文、公告、历史版本或者其他相关页面的链接 |

## 记录维护

管理组发布新的修订提案、调整公示状态、确定施行日期、撤回修订或者结束施行后公示期时，应当及时更新本页面。

更新修订状态时，应当保留原有修订编号，不得通过删除历史记录掩盖已经公示、施行、撤回或者被取代的修订。记录存在错误时，可以作出订正，但应当避免改变原修订事项的实质内容。
